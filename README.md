# Letrola 🎮

[![Deploy](https://img.shields.io/badge/deploy-vercel-black)](https://letrola-ten.vercel.app)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**Letrola** é um jogo educacional infantil desenvolvido para auxiliar no processo de alfabetização de crianças em fase de letramento. Através de uma narrativa lúdica ambientada em uma selva colorida, o jogo oferece atividades interativas que estimulam o reconhecimento de letras, formação de palavras e desenvolvimento da consciência fonológica.

## 🎯 Objetivo

O projeto tem como finalidade tornar o aprendizado das letras e da leitura uma experiência divertida e envolvente, utilizando mecânicas de jogo para manter as crianças motivadas durante o processo educacional.

## 🌟 Funcionalidades

### Narrativa Temática
- **Contexto**: Os animais da selva estão organizando uma grande festa e precisam da ajuda do jogador
- **Personagens**: Macaco Abú, Urso Polado, Sapo Hebert, entre outros
- **Progressão**: Sistema de mapas com cinco mundos distintos

### Minijogos Educacionais

O jogo oferece cinco tipos diferentes de atividades pedagógicas:

1. **Arrastar Letras**: Exercícios de reconhecimento e coordenação motora através do drag-and-drop
2. **Pesca de Letras**: Identificação de letras em contexto lúdico
3. **Palavras Cruzadas**: Formação de palavras e associação letra-som
4. **Caça-Palavras**: Busca visual e reconhecimento de palavras completas
5. **Jogo da Memória**: Associação entre imagens e palavras para fixação do vocabulário

## 🚀 Como Executar

### Pré-requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/carolsoul/Letrola.git

# Entre no diretório do projeto
cd Letrola

# Instale as dependências
npm install

# Execute o frontend
cd frontend
npm start

# Em outro terminal, execute o backend
cd backend
npm start
```
